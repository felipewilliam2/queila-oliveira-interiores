## 🏠 Sobre o Projeto

Sistema completo de gestão de projetos de design de interiores desenvolvido especialmente para **Queila de Oliveira Interiores**. Uma ferramenta profissional e intuitiva para gerenciar todos os aspectos de projetos de decoração e design de interiores.

### ✨ Funcionalidades Principais

- **📊 Dashboard Completo** - Visão geral do progresso dos projetos
- **📅 Gestão de Cronograma** - Visualizações em Gantt, Kanban e Lista
- **💰 Controle Financeiro** - Gestão completa de orçamentos e despesas
- **📁 Documentos e Contatos** - Centralização de arquivos e informações da equipe
- **📖 Diário de Obra** - Registro detalhado do progresso dos projetos
- **🛒 Planejamento de Aquisições** - Controle de compras de materiais e mobiliário

## 📋 Funcionalidades Detalhadas

### 📊 Dashboard
- Progresso geral dos projetos
- Alertas de orçamento em tempo real
- Lista de próximas tarefas
- Ações rápidas para todas as funcionalidades

### 📅 Cronograma
- **Visualização Gantt** - Timeline visual dos projetos
- **Quadro Kanban** - Gestão ágil de tarefas (A Fazer, Em Andamento, Concluído)
- **Lista Detalhada** - Visão completa com status, datas e responsáveis

### 💰 Gestão Financeira
- Resumo orçamentário detalhado
- Gráficos de gastos por categoria
- Controle de despesas por projeto
- Alertas de orçamento

### 📁 Documentos e Contatos
- Upload e organização de documentos
- Lista de contatos da equipe
- Informações de contato com ação de ligação direta

### 📖 Diário de Obra
- Registro cronológico do progresso
- Entradas com data, título e descrição
- Histórico completo dos projetos

### 🛒 Planejamento de Aquisições
- Lista de compras com status
- Controle de quantidades e fornecedores
- Datas limite para aquisições
- Alternância de status (Pendente/Comprado)

## 🚀 Como Usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/SEU_USUARIO/queila-oliveira-interiores.git
   ```

2. **Abra o arquivo `index.html`** em seu navegador

3. **Navegue pelas funcionalidades** usando o menu superior

## 🎨 Personalização

### Cores e Tema
As cores podem ser facilmente personalizadas no arquivo `style.css` através das variáveis CSS:

```css
:root {
  --color-primary: #21805D;
  --color-secondary: #D97706;
  --color-background: #F9FAFB;
}
```

### Dados Iniciais
Os dados de exemplo podem ser modificados no arquivo `app.js` na seção `appData`.
